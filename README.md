# Real Estate Property Management

Salesforce assignment built using Apex and Lightning Web Components (LWC).

### Implemented
- Property listing with pagination and rent/status filters.
- Property creation with file upload support.
- Tenant and lease workflow with onboarding tasks.
- Maintenance requests with least-workload vendor assignment.
- Lease PDF download using jsPDF.
- Scheduled Apex for lease expiry reminders.

### Tech Stack
Apex · LWC · SOQL · Salesforce Files · Scheduled Apex · JavaScript · jsPDF

### Tests
12 Apex tests passed. All main project Apex classes have over 80% individual code coverage.

**Note:** Nearby property search, reports, some property fields, and PDF email delivery still need implementation or verification.
